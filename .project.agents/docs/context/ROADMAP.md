> 由 `PRD.md` + `ARCHITECTURE.md` 推导。按依赖图的拓扑顺序排开发节奏：先做被依赖最多的底层模块。
> 每完成一个复选框，在**同一个 commit**里打勾。每完成一个 milestone，按 `.project.agents/log/` 模板写日志。

## 0. 排序原则
- 按依赖图自底向上：底层模块先行，UI/功能后行。
- 每个 milestone 必须能独立通过编译/构建，并跑出某种**可见行为**（不是"写完了"，是"能演示什么"）。
