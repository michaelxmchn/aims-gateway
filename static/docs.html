AIMS Network Developer Guide

How to connect, use Skills, earn USDC, and contribute to the mesh. No sign-up forms, no approvals, no subscriptions — just your EVM wallet.

Quickstart: Run Your First Skill in 60 Seconds

You need two things: an EVM wallet and Python 3.10+.

⚡ Dev mode: Every new wallet gets 10.0 USDC auto-seeded — enough for ~200 free invocations. No deposit needed.

Install the SDK

pip install eth-account requests

Create or import a wallet

# Generate a new wallet (for testing)
from eth_account import Account
wallet = Account.create()
print(f"Address: {wallet.address}")
print(f"Key: {wallet.key.hex()}")

# Or use an existing one
wallet = Account.from_key("0xYourPrivateKey...")

Sign and run a Skill

# scrape_products.py
import json, time, requests
from eth_account import Account
from eth_account.messages import encode_defunct

wallet = Account.from_key("0xYourPrivateKey...")

body = json.dumps({
    "skill_id": "amazon_scraper",
    "params": {"search_term": "RTX 5090", "max_results": 3},
    "user_id": wallet.address,
}, separators=(',', ':'))

signable = encode_defunct(primitive=body.encode())
signed = wallet.sign_message(signable)

headers = {
    "X-Wallet-Address": wallet.address,
    "X-Signature": signed.signature.hex(),
    "X-Timestamp": str(int(time.time())),
    "Content-Type": "application/json",
}

r = requests.post(
    "https://aims-gateway.fly.dev/api/run",
    data=body, headers=headers,
)
task_id = r.json()["task_id"]
print(f"Task: {task_id}")

# Poll until done
for _ in range(30):
    time.sleep(2)
    r = requests.get(f"https://aims-gateway.fly.dev/api/tasks/{task_id}/status")
    data = r.json()
    if data["status"] == "SUCCESS":
        print(data["result"])
        break
    elif data["status"] == "FAILED":
        print("Failed:", data)
        break

ⓘ No worker running? The task stays PENDING until a worker claims it. In production, workers are always online. For local testing, start a worker with python -m src.worker.worker.

Three Ways to Use AIMS

Your wallet is your passport to all three roles. You can switch at any time — no re-registration needed.

▶ Use Skills (Consumer)

Browse the Skill registry, pick what you need, and invoke it via the API. You pay only on success — failed tasks auto-refund.

↑ Publish Skills (Developer)

Write a Python module, package it with a manifest, and upload it. Every time someone invokes your Skill, you earn a developer premium.

  1. Create manifest.json (name, description, input/output schema, price)
  2. Create logic.py with an execute(payload) → dict function
  3. Zip them together: zip my_skill.zip manifest.json logic.py
  4. POST the zip to /api/skills/upload
curl -X POST https://aims-gateway.fly.dev/api/skills/upload \
  -F "zip_file=@my_skill.zip"

⚙ Run a Node (Worker / Provider)

Two ways to earn:

  • Worker — claim pending tasks, execute Skill logic, submit results. Earn 80% of the task fee.
  • Provider — route encrypted traffic through your residential IP when idle. Get paid for bandwidth.
# Start a worker
AIMS_WALLET_KEY=0x... python -m src.worker.worker

# Or run as a provider (idle bandwidth)
from aims.provider import ResidentialRouteProvider
provider = ResidentialRouteProvider(wallet=your_wallet, region="us-west")
provider.start()

How Billing Works

No subscriptions. No monthly fees. You pay per successful invocation, and the split is automatic.

ItemAmountWho Gets It
Base task fee0.05 USDC80% worker / 20% protocol
Compute gas$0.01/sec (Tier-1)Worker

Platform tax1% of totalProtocol treasury

Failed task? Your USDC never leaves escrow. The 402 safeguard rejects requests with insufficient balance before any funds move. If a worker fails to deliver valid results, the escrow refunds automatically.

Authentication

AIMS uses EIP-191 personal_sign — the same signature format your wallet uses to sign transactions. No API keys, no bearer tokens, no shared secrets.

Every POST request to a protected endpoint needs three headers:

X-Wallet-Address: 0xYourEVMAddress
X-Signature:      <EIP-191 hex signature of the raw body>
X-Timestamp:      <UNIX epoch seconds>

The signature must be over the exact request body bytes (compact JSON, no extra whitespace):

# Python signing (client-side)
from eth_account.messages import encode_defunct

body = json.dumps(payload, separators=(',', ':'))  # compact!
signable = encode_defunct(primitive=body.encode())
signed = wallet.sign_message(signable)
signature_hex = signed.signature.hex()

Timestamps older than 300 seconds are rejected (replay protection).

Common Questions

Do I need to deposit real money?

Not in dev mode. The gateway auto-seeds 10.0 USDC for testing. When mainnet launches, you'll deposit real USDC to the settlement contract on Base L2.

What if a Skill fails?

Your USDC is never deducted. The escrow is automatically refunded. The worker receives a strike — three strikes = $1.00 slashed from their staked collateral.

Can I run this from a browser?

Not yet. AIMS is an API-first protocol designed for agents and developers. The primary interface is HTTP + your wallet. A web dashboard is on the roadmap.

What chains do you support?

Settlement runs on Base (EVM L2). Any EVM wallet works for auth — MetaMask, Rabby, Frame, or a raw key.

Is my data private?

Task payloads are encrypted in transit. Provider nodes see only encrypted bytes and routing metadata — never the content. Worker nodes receive only the task parameters, not your identity.
